# Localization Workspace（本地化工作台）— 用户使用指南

> 一个软件，搞定游戏汉化的所有事。

---

## 这是什么软件？

**Localization Workspace（简称 LW）** 是一款一体化的游戏汉化工具，把过去需要好几款软件才能完成的工作整合到了一起。

不管你是**想玩汉化游戏的普通玩家**，还是**想自己做汉化的制作者**，都能用这一个软件搞定。

---

## 能做什么？

### 三大汉化通路，覆盖所有场景

| 通路 | 说明 | 适合谁 |
|------|------|--------|
| 📦 **资源补丁制作** | 解包游戏文件 → 提取文本 → 翻译 → 打包成汉化补丁 | 汉化制作者 |
| 🔌 **内存Hook翻译** | 不修改游戏文件，运行时实时翻译游戏文字 | 普通玩家（单机游戏） |
| 👁️ **OCR屏幕翻译** | 识别游戏画面上的文字，悬浮显示译文 | 普通玩家（所有游戏） |

### 补丁社区Hub

软件内置**汉化补丁社区**，你可以：
- 🔍 搜索、浏览其他玩家分享的汉化补丁
- ⬇️ 一键下载补丁
- ✅ 一键安装到游戏（自动备份原文件，不怕搞坏）
- 📤 把自己做的汉化补丁分享给社区

## 下载与安装

### 系统要求

- Windows 10（1809及以上）或 Windows 11
- .NET 10 运行时（安装包会自动检测并提示安装）
- 至少 2GB 内存
- 至少 500MB 可用磁盘空间

### 安装步骤

1. 下载最新版安装包（`.exe` 格式）
2. 双击运行安装包
3. 按照提示完成安装（建议使用默认路径）
4. 桌面会生成「Localization Workspace」快捷方式
5. 双击启动软件

> 首次启动时，如果系统缺少 .NET 10 运行时，软件会自动提示下载安装。

## 快速上手

### 场景一：我是普通玩家，想玩汉化游戏

**方式A：使用社区汉化补丁（推荐）**

1. 打开软件，点击左侧「补丁社区Hub」
2. 在搜索框输入游戏名称（如"群星"、"Minecraft"）
3. 找到合适的汉化补丁，点击「下载」
4. 下载完成后点击「一键安装」
5. 选择游戏安装目录，软件会自动备份原文件并安装补丁
6. 启动游戏，享受汉化！

**方式B：内存Hook实时翻译（适合没有汉化补丁的单机游戏）**

1. 先启动游戏
2. 打开软件，点击左侧「内存Hook翻译」
3. 点击「扫描进程」，选择游戏进程
4. 点击「附加」，软件会自动抓取游戏中的文字并翻译
5. 翻译结果实时显示在软件窗口中

> ⚠️ **注意**：内存Hook仅支持**单机离线游戏**。带反作弊的联机游戏（如EAC、BattlEye）禁止使用，否则可能导致账号封禁！

**方式C：OCR屏幕翻译（兜底方案，所有游戏都能用）**

1. 打开软件，点击左侧「OCR屏幕翻译」
2. 选择识别模式（推荐「窗口绑定」，选择游戏窗口）
3. 点击「开始识别」
4. 游戏画面上的文字会被识别并翻译，译文悬浮显示在屏幕上
5. 可以调整悬浮窗的位置、大小、透明度

---

### 场景二：我是汉化制作者，想做汉化补丁

**完整工作流：**

1. **新建工程**
   - 点击「新建工程」
   - 选择游戏安装目录，软件会自动识别游戏引擎
   - 填写工程名称、选择源语言（如英语）和目标语言（如简体中文）

2. **扫描并提取文本**
   - 点击「资源解析」，软件会扫描游戏中的所有文本资源
   - 点击「提取文本」，把游戏里的文字全部提取出来
   - 提取完成后，可以在「翻译编辑」页面看到所有文本

3. **翻译文本**
   - 在「翻译编辑」页面逐条翻译
   - 可以使用「AI机翻」批量预处理（需要配置翻译API）
   - 软件会自动记住你翻译过的内容（翻译记忆库），相同的句子自动匹配
   - 专业术语可以添加到「术语库」，确保翻译一致

4. **质量检查**
   - 点击「质量检查」，软件会自动检测：
     - 未翻译的文本
     - 术语不一致
     - 变量占位符缺失（如 `{0}`、`%s`）
     - 译文过长可能导致UI溢出
   - 根据检查结果修正问题

5. **导出补丁**
   - 点击「导出中心」
   - 选择导出格式（如「MOD文件夹」、「.lwp补丁包」）
   - 点击「导出」，生成汉化补丁
   - 可以选择「发布到社区」，把补丁分享给其他玩家

## 常见问题（FAQ）

### Q1：这个软件收费吗？

A：软件本身**免费使用**，但属于专有软件，仅限个人非商业用途。禁止用于商业汉化服务、收费汉化等商业行为。

### Q2：支持哪些游戏？

A：理论上支持所有PC游戏，但不同游戏的汉化方式不同：
- **有资源文件的游戏**（如Unity、UE、P社游戏、Minecraft）：可以制作完整汉化补丁
- **硬编码文本的老游戏**：可以用内存Hook实时翻译
- **所有游戏**：都可以用OCR屏幕翻译（兜底方案）

软件通过**插件系统**支持不同引擎，目前官方支持P社游戏和Minecraft，更多引擎插件正在开发中。

### Q3：用内存Hook会被封号吗？

A：**单机游戏不会**。但**带反作弊的联机游戏绝对不要用**，软件会自动检测反作弊进程并禁止附加。常见反作弊包括：EAC（Easy Anti-Cheat）、BattlEye、Vanguard（Valorant）、VAC（Steam）等。

### Q4：安装汉化补丁会搞坏游戏吗？

A：不会。安装补丁前软件会**自动备份原始文件**，如果出问题可以在「本地补丁管理」中一键卸载恢复。建议首次使用前先手动备份游戏存档。

### Q5：OCR翻译准确率怎么样？

A：OCR识别准确率取决于游戏画面的清晰度和字体。建议：
- 使用窗口模式或无边框窗口模式
- 确保游戏文字清晰、对比度高
- 可以在设置中调整图像预处理参数（灰度化、放大、去噪）提升识别率

### Q6：AI机翻怎么用？

A：需要先在「设置 → 机翻API」中配置翻译服务（如百度翻译、DeepL等），填入API Key。配置完成后可以在翻译编辑页面使用「批量机翻」功能。API Key会加密存储，不会泄露。

### Q7：软件打不开 / 闪退怎么办？

A：
1. 确认已安装 .NET 10 运行时
2. 查看日志文件（`%APPDATA%/LocalizationWorkspace/logs/`），找到错误原因
3. 尝试以管理员身份运行
4. 如果仍有问题，联系技术支持并附上日志文件

### Q8：可以把软件分享给朋友吗？

A：可以免费分享给个人使用，但**禁止修改、反编译、二次打包分发**，也禁止用于商业用途。
